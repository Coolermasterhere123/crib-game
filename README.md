# Crib Card Game

A full cribbage-style card game built with Next.js.

## Features
- 🃏 Play against the computer
- 🔄 Alternating dealer each round
- 📊 Live score tracking with history
- 👀 Cards displayed as they're played
- 🎯 Scoring phase with pair detection
- 🎨 Modern dark theme
- 📱 PWA enabled
- 🚀 Port 3005

## How to Play
1. Each player gets 6 cards
2. Select 2 cards to put in the crib
3. Take turns playing cards to reach 15 or 31 for bonus points
4. Scoring phase counts pairs and crib points
5. Dealer alternates each round

## Deployment
- Auto-deploys to Vercel via folder-watcher
- Drop the ZIP into your watched folder
